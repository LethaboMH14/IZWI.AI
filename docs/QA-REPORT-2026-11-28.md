# QA report, 28 November 2026

**Build tested:** `merge/main-into-redesign` at `5eb8aa1`, plus the fixes in this change (branch `qa/full-pass`). **Live site:** https://izwi-ai-six.vercel.app runs `main` at `b43b510`, without the redesign. Neither branch had moved at 08:37 SAST.

## Verdict

- **`5eb8aa1` as it stands is not ready for the demo.** On local storage an upload sits at 0% and never opens the story; Groq, Gemini and AI/ML API can't be added; a held render can stay held for good.
- **With these fixes the demo flow worked locally,** end to end: sign up, upload, transcript and scenes, declaration, guest consent on a phone-sized page, render, download, provenance check, translation, review link, listing and enquiry.
- **Not proven on the hosted stack.** No real Postgres server, Supabase, live R2 or Vercel deployment ran this build. After any deploy, sign in, upload a short file and render one clip before relying on it.
- **Most fixes are also needed on `main`,** so the live site has those defects today. They are prepared and tested on branch `qa/main-fixes`; see [On `main`](#on-main).
- **For the noon decision:** if the redesign goes in, take `qa/full-pass`, not `5eb8aa1` alone. If it doesn't, take `qa/main-fixes`.

## Resetting the demo

The old snapshot steps (PR 12, `docs/demo-reset` branch) copy `storage/izwi.db`. The app no longer uses that file, so **they don't reset anything now**, and an old SQLite snapshot can't be loaded.

A snapshot now needs all of these, taken together with the app and worker stopped:

1. A dump of the Postgres database.
2. The media: `web/storage`, or the bucket's objects.
3. The same `IZWI_MASTER_KEY` (provider keys and the consent ledger depend on it) and `BETTER_AUTH_SECRET`.

No dump and restore was tried. The tested way to start fresh is a new story from the same recording: on this laptop the transcript and scenes were ready in about 20 s. Then record the declaration, add the guest and ask for consent again.

## Before presenting

1. Teach the spellings "Sawubona Mzansi" and "Jozi Stories".
2. Have a translation and one finished render ready; local translation takes about two minutes.
3. If the assistant is shown, set the flags in both the app and worker, send one message beforehand, and keep a recorded run as a fallback.
4. Make a fresh consent link after any address change or reset; it's shown once and lasts 14 days.
5. Keep the worker running; without it uploads and renders wait in the queue.

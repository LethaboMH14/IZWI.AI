# Seasonal looks and ideas

Status: partial. `IZWI_FLAG_SEASONAL_LOOKS=0` keeps the feature off. When enabled, an account must opt into suggestions in Settings before Home shows a calendar proposal. Dates cover South African summer/winter, Heritage Day, Youth Day, Women's Day, the festive season and back to school. The content ideas and style mapping are data, not generated by an agent. The look changes only after the creator explicitly accepts; the creator can dismiss the proposal or turn seasonal suggestions off in Settings. The palette uses amber, terracotta, forest and ocean; no purple.

Theme mappings reuse the existing appearance presets. Calendar ideas are suggestions, not factual claims about event performance. Checks: `web/tests/seasonal-looks.test.ts`, `web/tests/migration-history.test.ts`, `web/e2e/seasonal-looks.spec.ts`; browser screenshots require owner state.

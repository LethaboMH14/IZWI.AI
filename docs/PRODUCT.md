# Product requirements
## Promise
A connected creative workspace that helps independent creators turn original work into accessible, distribution-ready and potentially commercially valuable assets. This is an intended benefit, not a guarantee of income or audience growth.

## Five pillars
| Pillar | Intended behaviour | First-release boundary |
|---|---|---|
| Create | Import media, describe intent, suggest clips, edit cuts and captions | One project and an editable export workflow |
| Localise | Draft subtitles/translations, preview timing, accept corrections | One evaluated language pair; no claim to all languages |
| Protect | Record declarations, consent, collaborator agreements and provenance references | Basic records and approvals, not ownership adjudication |
| Publish | Export suitable formats and later connect approved platforms | MP4/SRT export and distribution preparation first |
| Earn | Licensing enquiries, store listings, eligible transactions | Mocked/planned; commerce follows technical and legal validation |

Audience intelligence is a feedback layer, using consented connected metrics where access permits. Model adapters and agentic actions remain scoped and reviewable.

## Persona and journey
Naledi is a fictional Johannesburg podcaster representing an early adopter, not a user interview.
1. Create a private project and import Episode 04; upload can resume.
2. Ask for useful short clips. Review suggestions and edit boundaries.
3. Correct source captions, request an evaluated language draft and review idioms/names.
4. Record creator declaration and collaborator/consent requirements; resolve outstanding items.
5. Choose aspect ratio, review preview and export media/captions.
6. Prepare a supported publishing action only after connecting an account.
7. Later, prepare licence/store offerings with transparent fees.
8. Review connected metrics and reuse project preferences.

## MVP acceptance
- Users cannot read another workspace's private assets.
- A supported input completes the upload → reviewed captions → MP4/SRT export journey.
- User edits survive retries; a retry cannot create duplicate billing.
- Unsupported format, oversize file, interruption, exhausted credits and failed render produce actionable messages.
- Translation stays marked draft until explicitly approved.
- Consent requirements can block the relevant action.
- No platform connection means no scheduled/published success state.
- Usage price/allowance is shown before paid processing.
- Deletion/retention and failure recovery are documented.

## Platform/device roles
Laptop: editing, detailed review and project management. Phone: quick review and approval. Tablet: collaboration and annotation. These are views of one project, not separate products.

## Out of first-release scope
Unbounded autonomous agents, all model providers, guaranteed low-spec local inference, all official-language support, automatic voice cloning, full marketplace payouts, rights certification and every social platform.

## Research gates
Observe actual existing workflows and spending; validate willingness to pay; evaluate speech/translation by language and code-switching; benchmark device/GPU performance and cost; confirm platform scopes and payment/commerce capabilities.

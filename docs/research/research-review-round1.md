**ASR evaluation and routing**

- **Q4/Q5** — Mann–Whitney assumes independent samples. Scoring both systems on the same clips violates that assumption, and repeated speakers add dependence. Use a paired permutation test that swaps system labels together within independent speaker/episode groups, plus a paired cluster-bootstrap CI for the WER difference. [Mann–Whitney assumptions](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.mannwhitneyu.html)
- **Q2/Q4/Q5** — Mean clip WER and corpus WER weight clips differently. Ordinary Cliff’s delta discards pairing, and merely reporting it cannot establish a win. Prespecify the primary measure, report the absolute paired WER improvement in percentage points with its CI, and define the minimum worthwhile improvement.
- **B2/B6/G2** — Eight languages × three settings × three switch categories gives up to **14,400 pilot utterances** at 200 per populated cell. Raw WER variance cannot power a paired comparison, and 100 total API calls cannot guarantee power across four languages. Choose feasible primary contrasts and size them from pilot **paired differences**, independent speaker counts, target improvement, alpha and power. Run both systems on the identical API subset.
- **B5/K1–K5/I** — The split covers dev versus test, but creator training clips, accepted transcripts, glossary entries and near-duplicate excerpts can still leak into evaluation. Assign connected speakers and episodes to train/dev/test before segmentation, deduplicate across sources, and exclude test-derived text from correction and language-model training.
- **B5/Q5/E/K1/I** — “Once per comparison” repeatedly exposes the same test set. Choosing weak test cells for fine-tuning makes that set development data. Select models, corrections and thresholds on dev, freeze one primary comparison, adjust secondary comparisons for multiplicity, and use a fresh holdout after test-driven changes.
- **B3/B4/Q3** — “Wrong language or script” is unscorable from reference-only tags when both languages use Latin script. Freeze tokenisation and alignment, define mixed WER as `(S+D+I)/reference words`, English recall as `correctly aligned English words/reference English words`, and score switch-boundary precision/recall using independently labelled hypotheses. Specify rules for insertions, borrowings, mixed words and zero denominators. [Documented within-word switching in SA speech](https://lrec.elra.info/lrec2018-main-451)
- **B2/D/R2/K5** — The router covers isiNdebele and Tshivenda without evaluation cells. L1 supplies no validated Bantu-family detector, and K5’s D1 lacks the English/Afrikaans negatives needed for that decision. Add route-specific test coverage and an unknown/abstain outcome. Use creator declarations until the detector passes.
- **A8/H6/H7/E1** — The whisper.cpp evidence establishes token probabilities. It does not establish the same word score as faster-whisper, and CTC frame posteriors require alignment. Define each runtime’s token-to-word aggregation and calibrate confidence on labelled dev errors before enabling fallback.
- **H1/H6/D** — A published CTranslate2 int8 conversion already exists, and its maintainer documents that faster-whisper cannot force the seven SA language codes. Keep the creator declaration as routing metadata and test the converted model’s decoding and accuracy against the original. [Conversion and decoding instructions](https://huggingface.co/digiphyte/swivuriso-turbo)

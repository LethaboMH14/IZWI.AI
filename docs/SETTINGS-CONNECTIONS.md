# Settings: Connections

**Status: partial.** The default-off Settings > Connections screen guides the creator from a provider group to a provider-specific step. It loads model options through the existing guarded provider client, allows task selection, then saves and tests through the existing provider route. Keys are sealed on the server. Current test results explain likely next steps. The role controls for Find clips and Transcribe were removed because these jobs do not use hosted provider routes; the API no longer accepts those role assignments, and stale task routes are discarded when routes are saved.

Enable with `IZWI_FLAG_CONNECTIONS=1` in `web/.env.local` and restart the app. The default is off. `/app/engine` still contains device, worker, passkey and advanced provider controls. The Settings menu link appears only when this server flag is on.

Local Ollama is treated as Private only for a loopback address; this cannot prove a custom local service does not forward requests. whisper.cpp runs through the local worker, with audio processed on that worker. Ollama and whisper.cpp use the MIT licence. Groq and Gemini are offered as online free-tier services; Meta Model API, OpenRouter and AI/ML API are paid hosted services. These hosted options are not described as open source. Their privacy classes are May log except Meta Model API, which is Standard.

Model discovery displays the Rand cost estimate for a typical turn when the provider has live or reviewed pricing and the server has `IZWI_USD_ZAR` plus its date configured. Models without an available Rand estimate say **price unknown**. Price tags are estimates and do not guarantee an account's price or free allowance. A provider test checks access, not remaining quota.

A paid assistant model needs an approved price entry, a positive `IZWI_USD_ZAR`, and `IZWI_ASSISTANT_DAILY_CENTS` above zero. If any is missing, the assistant refuses to use that model. The workspace owner must set the missing server values and restart the app. Marking a provider as free tier is an owner assertion, not an account check.

The API test for preview discovery uses a mocked guarded-fetch response and confirms the pasted key is neither returned nor stored as a provider. The Playwright test uses owner/member storage-state files (`IZWI_E2E_OWNER_STATE`, `IZWI_E2E_MEMBER_STATE`), a disposable Postgres-backed app on 127.0.0.1:4300 with the flag on, and a second on 127.0.0.1:4301 with the flag off. The local worktree had no database or signed-in test sessions, so the browser test and 1440 px/375 px screenshots could not be run here. The test is `web/e2e/settings-connections.spec.ts`; its screenshot outputs are `design/mockups/settings-connections-desktop.png` and `design/mockups/settings-connections-mobile.png`.

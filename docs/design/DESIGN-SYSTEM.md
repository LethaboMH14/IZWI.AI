# Design baseline
## Identity
IZWI AI, by Team Sonar. Core sequence: Create · Localise · Protect · Publish · Earn.
Approved headline: Turn one story into many. CTA: Try IZWI AI.
Never rename to MzansiCreator OS.

## Appearance
Light white and warm ivory surfaces, amber/gold accent, charcoal text. No purple, violet or default dark theme.
Retain the supplied Figma Slides cover's spacious typography and angled devices. Presentation font: Plus Jakarta Sans. Suggested implementation roles (evaluate contrast before production):
- background #FFFFFF
- warm background #FAF8F4
- surface #F0ECE4
- text #242424
- muted text #666666
- amber action #B77913
- amber tint #FFE0A0
- border #DDDDD7
Use clear focus states, readable contrast, labelled icons and responsive layouts. A raster reference is not proof of accessible implementation.

## Character/content consistency
Use the existing fictional Naledi with short natural hair, ochre jacket, black shirt and headphones in a warm studio. assets/current/presentation/slides/03.png is the authoritative character reference. Reuse supplied imagery rather than regenerating a different identity. Podcast content is illustrative; broader creator segments remain in scope.

## UI
One project connects all stages. Laptop edits; phone reviews; tablet collaborates. Create shows preview, timeline, waveform and editable captions. Localise shows draft/review states. Protect distinguishes declarations from verified rights. Publish distinguishes prepared export from connected/published status. Earn distinguishes options from transactions and paid-out amounts.
Do not show fabricated revenue, success, language support or signed consent.
Use reusable components, semantic controls and editable design layers. Keep screens demonstrative until wired to real state.
